# 🐰🎀 Убежище для Котёнка-Зайчика (Сайт-сюрприз)

Трогательный и уютный сайт-сюрприз для твоей девушки, оформленный в нежном кокет-стиле с кружевными мотивами, персонажами в духе плюшевых игрушек **Jellycat** и вашими личными шутками.

---

## 🌟 Что внутри:
1. **SVG-иллюстрация плюшевого Jellycat Bashful Bunny** с длинными ушками, вельветовыми ножками и атласным бантиком.
2. **Ажурные кружевные элементы** (верхний бордюр, кайма карточек, кружевные уголки конвертов).
3. **Официальная немецкая справка «Няшинг-Термин» (Bundesamt für Liebe & Kuscheln)** с печатью *BESTÄTIGT*, где прописано:
   - Тотальное зацеловывание (100% покрытие).
   - Обнимашки до мурчания.
   - Облизывание с ног до головы (*«Weil sie die Allerleckerste ist»* / потому что самая вкусная!).
   - Режим «Няшиться 24/7».
4. **Интерактивный пульт скорой помощи при грусти**:
   - 💋 *«Зацеловать прямо сейчас»* — залп поцелуев и сердечек по всему экрану.
   - 🧸 *«Jellycat-обнимашка»* — плюшевые объятия.
   - ✨ *«Режим МИМИМИМИМИ»* — счётчик милоты с поднимающими настроение фразами и мелодией.
   - ☕ *«Горячий чай»* — виртуальный уют.
5. **6 кружевных конвертов «Открыть, когда...»**:
   - когда задолбали немецкие амты и бюрократия;
   - когда накатила тоска и хочется на ручки;
   - когда кажется, что силы на исходе;
   - когда забыла, какая ты невероятно милая и вкусная;
   - перед сном;
   - когда срочно нужно «мимимимими».
6. **Баночка с записками «Почему ты самая-самая»**:
   - Интерактивная баночка с леденцами, из которой можно кликом доставать нежные причины.
7. **Звуки уюта (работают без интернета)**:
   - Встроенный генератор расслабляющего шума дождя и нежных колокольчиков (через Web Audio API).

---

## 🚀 Как посмотреть сайт прямо сейчас на компьютере:

Просто открой файл в браузере:
- Найди файл `index.html` по пути:
  `/Users/millyrock/.gemini/antigravity/scratch/for-my-bunny/index.html`
- Дважды кликни по нему или открой в Chrome / Safari.

---

## 📸 Как добавить ваши фотографии:
1. Создай папку `images` рядом с `index.html`.
2. Положи туда ваши совместные фото (например, `photo1.jpg`, `photo2.jpg`).
3. Ты можешь вставить их прямо в конверты или добавить отдельную галерею в `index.html`.

---

## 🎙️ Как добавить своё голосовое сообщение:
1. Запиши на диктофон тёплое сообщение для неё (1-2 минуты).
2. Назови файл `voice.mp3` и положи в эту папку.
3. В `index.html` раскомментируй стандартный аудиоплеер:
   ```html
   <audio controls src="voice.mp3" style="width: 100%; margin-top: 10px;"></audio>
   ```

## 🌐 Как бесплатно выложить в интернет (чтобы отправить ей ссылку):

### Способ 1: Netlify Drop (самый быстрый, 30 секунд без кода)
1. Зайди на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Просто перетащи всю папку `for-my-bunny` в окно браузера.
3. Сайт мгновенно опубликуется и выдаст готовую ссылку вида `cute-bunny-12345.netlify.app`. Можно сразу скопировать и отправить ей в Telegram/WhatsApp!

### Способ 2: GitHub Pages или Vercel
- Можно загрузить в свой репозиторий GitHub и включить Pages в настройках репозитория.
